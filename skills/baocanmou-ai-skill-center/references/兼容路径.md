# 兼容路径

| 用途 | 默认路径 | 行为 |
|---|---|---|
| 中心源 | `~/.agents/skills` | 唯一技能事实 |
| 中文校正 | `~/.baocanmou/skill-center/translations.json` | 只保存名称与说明 |
| Codex | `~/.codex/skills` | 受控连接 |
| Claude Code | `~/.claude/skills` | 受控连接 |
| Gemini CLI | `~/.gemini/skills` | 按需连接 |
| Cursor | `~/.cursor/skills` | 按需连接 |
| Hermes | `~/.hermes/skills` | 按需连接 |
| ZCode | `~/.zcode/skills` | 按需连接 |
| OpenCode | `~/.config/opencode/skills` | 按需连接 |
| Windsurf | `~/.windsurf/skills` | 按需连接 |
| Kimi Code CLI | 直接读取 `~/.agents/skills`（自有目录 `~/.kimi-code/skills`，可由 `KIMI_CODE_HOME` 改根目录） | 无需连接，不另建入口 |
| 文心快码 Comate | `~/.comate/skills` | 按需连接 |
| Qwen Code | `~/.qwen/skills` | 按需连接 |
| TRAE（国际版） | `~/.trae/skills` | 按需连接 |
| TRAE CN（国内版） | `~/.trae-cn/skills` | 按需连接 |

表中 `~` 在 Windows 上即 `%USERPROFILE%`，例如 TRAE 为 `%USERPROFILE%\.trae\skills`、TRAE CN 为 `%USERPROFILE%\.trae-cn\skills`。

Kimi Code CLI 在用户级同时扫描 `~/.kimi-code/skills` 和 `~/.agents/skills`，再给它建链接会让同一技能出现两份，所以只显示“直接读取中心源”。若用 `BAOCANMOU_SKILLS_HOME` 改了中心源位置，Kimi 读不到新位置，此时退回普通连接，入口为 `$KIMI_CODE_HOME/skills`（默认 `~/.kimi-code/skills`）。

项目级目录（`.qwen/skills`、`.trae/skills`、`.comate/skills`、`.agents/skills` 等）随项目仓库管理，技能中心不写入。

macOS/Linux 创建软链接。Windows 先尝试目录链接，权限不足时才复制，并写入 `.baocanmou-managed-copy` 标记。没有标记的目录一律视为非托管冲突。
